# Portfolio Summary

## Pediatric Hospital Throughput Analytics Demo

Built a synthetic pediatric encounter analytics workflow in Microsoft Fabric, transforming 1,000 encounter records into a curated reporting table using a Lakehouse structure and Dataflow Gen2. Created a Power BI semantic model and executive dashboard to analyze encounter volume, average length of stay, emergency admission percentage, long-stay rate, discharge patterns, and 30-day readmission rate.

**Tools:** Microsoft Fabric, Dataflow Gen2, Lakehouse, Power BI, DAX, CSV, healthcare operations analytics

**Business focus:** provider operations, pediatric throughput, length of stay, admission mix, and readmission monitoring.
